03 Feature-by-Feature Deep Dive

1. TV Order Status Display Board (Customer Lounge)
Route: /display

Designed for large wall-mounted screens in the customer waiting area and takeout counter.

  • Split 2-Column Design: Left column displays amber/blue "PREPARING" tickets; right column showcases large emerald "READY FOR PICKUP" tickets.
  • No Scrollbars: Configured with overflow: hidden and proportional card sizing so the screen never displays ugly browser scrollbars on commercial TVs.
  • Audio Chimes & Autoplay Unlock: Modern browsers restrict audio autoplay until user interaction; added an unobtrusive dismissible top banner: "Click to enable chime alerts for ready orders".
  • Real-Time Sync: Lightweight polling interval (5 seconds) paired with WebSocket events keeps orders instantly synchronized with kitchen status changes.
2. Standalone Chef Kitchen Display System (KDS)
Route: /kitchen

Rugged, touch-screen-friendly tablet interface specifically engineered for line cooks and the head chef.

  • PIN Lock Protection: Kitchen staff log in using the designated credentials (chef / Prevakds@2026). Remembers authenticated state in localStorage for 12 hours so cooks don't have to log in repeatedly during busy shifts.
  • 2-Tier Command Toolbar: Top tier filters by order status (All, New, In Prep, Ready); bottom tier filters by food category (Pizzas, Pastas, Sides, Drinks) and order type (Dine-in, Takeaway, Delivery).
  • Color-Coded Timers: Dynamic timer on each ticket changes color based on elapsed time: Green (<15 min), Amber (15–25 min), Flashing Red (>25 min overdue).
  • Line-Item Strike-Off: Chefs can tap individual ingredients or items to strike them out as they are placed on the pass.
  • Completed Recalls Drawer: Tapping "Recalls" pulls out a sliding drawer showing recently completed tickets with instant "Recall to Board" capability.
3. 80mm Thermal Receipt Printing System (ESC/POS Compatible)
Client & Chef POS Printing

Integrated standard 80mm (3-inch) thermal printer support without requiring expensive third-party print server subscriptions.

  • Implemented In 3 Key Locations:
    1. Chef KDS Ticket Header (/kitchen) — Prints prep slip for the kitchen line.
    2. Admin KDS (/admin/kds) — Allows admin to print kitchen duplicate slips.
    3. Customer Live Order Tracker (LiveOrderTracker.js) — Customer "Print Receipt" button.
  • Format & Layout: Strict 80mm width formatting, high-contrast monospace typography, dashed separator borders, itemized quantities, customer details, delivery address, subtotal, taxes, and order timestamp.
4. Pickup vs Delivery Modal & Operating Hours Engine
Checkout Experience

Provides a seamless, modern fulfillment selection modal on the checkout page.

  • Fulfillment Switcher: Beautiful tabbed switcher between Store Pickup (shows outlet address, pickup timing estimate 20-30 mins, ₹0 delivery fee) and Home Delivery (full address, landmark, delivery instructions, dynamic delivery fee).
  • Operating Hours Validation: Backend engine (backend/src/lib/operatingHours.js) prevents customers from placing orders when the kitchen is closed, displaying user-friendly next-opening alerts.
